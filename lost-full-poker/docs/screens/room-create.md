# ルーム作成画面 仕様

『混沌』のルーム作成画面構成を踏襲。

## レイアウト
### 左側
- ルームID(4桁数字)表示
- **モード選択**(ノーマル/ロストフル)
- ゲーム設定ボタン(タップでゲーム設定モーダルを開く)
- ゲーム開始ボタン
- ルームから抜けるボタン
- ルーム解散ボタン

### 右側
- 参加プレイヤーの名前一覧:実際にルームへ参加している人だけを表示する(未参加の空き枠は表示しない)。ルーム作成直後はGM本人のみが表示された状態になる

### 右上
- 設定(歯車)アイコン ※ルール項目は含めない

## 権限
ゲームマスター(ルーム作成者)にのみ以下を表示。参加者には非表示。
- ゲーム開始ボタン
- ルーム解散ボタン
- モード選択などの各種設定項目
- ゲーム設定ボタン

## ゲーム設定ボタンの項目
タップするとモーダルが開き、以下の項目を設定できる。
- **初期チップ**(デフォルト1000を想定)
- **試合数**
- **ジョーカーの有無**(オンの場合、山札52枚+ジョーカー2枚の54枚になる)
- 他プレイヤーの**赤札推定額(ロストイン用)表示**のオン/オフ
- 他プレイヤーの**チップ額表示**のオン/オフ
- 他プレイヤーの**BET額表示**のオン/オフ
(表示トグルは混沌の「敵ライフ/マナ表示オン/オフ」と同じ方針。オフの項目は代替表示なしで完全非表示)

## チャット機能
混沌と同様の仕様。
- 宛先選択(「全体」または個別プレイヤー指定)
- 全体チャット/個別チャットの色分け表示(混沌ではゲーム画面で白文字/青文字)
- 送信ボタン
