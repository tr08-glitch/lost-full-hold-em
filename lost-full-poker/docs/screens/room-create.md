# ルーム作成画面 仕様

『混沌』のルーム作成画面構成を踏襲。

## レイアウト
### 左側
- ルームID(4桁数字)表示
- **モード選択**(ノーマル/ロストフル)
- **参加人数設定**(2〜6人)
- 初期チップ設定欄(デフォルト1000を想定)
- 試合数設定欄
- ゲーム設定ボタン(詳細設定は今後実装)
- ゲーム開始ボタン
- ルームから抜けるボタン
- ルーム解散ボタン

### 右側
- 参加プレイヤーの名前一覧(2〜6人分)

### 右上
- 設定(歯車)アイコン ※ルール項目は含めない

## 権限
ゲームマスター(ルーム作成者)にのみ以下を表示。参加者には非表示。
- ゲーム開始ボタン
- ルーム解散ボタン
- モード選択・参加人数・初期チップ・試合数などの各種設定項目
- ゲーム設定ボタン

## ゲーム設定ボタンの項目(想定)
詳細な設定画面は今後実装するが、現時点で以下の項目を含む想定。
- 他プレイヤーの**赤札推定額(ロストイン用)表示**のオン/オフ
- 他プレイヤーの**チップ額表示**のオン/オフ
- 他プレイヤーの**BET額表示**のオン/オフ
(混沌の「敵ライフ/マナ表示オン/オフ」と同じ方針。オフの項目は代替表示なしで完全非表示)

## チャット機能
混沌と同様の仕様。
- 宛先選択(「全体」または個別プレイヤー指定)
- 全体チャット/個別チャットの色分け表示(混沌ではゲーム画面で白文字/青文字)
- 送信ボタン
