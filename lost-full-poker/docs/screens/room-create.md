# ルーム作成画面 仕様

『混沌』のルーム作成画面構成を踏襲。

## レイアウト
### 左側
- ルームID(4桁数字)表示
- ゲーム設定ボタン(タップでゲーム設定モーダルを開く)
- ゲーム開始ボタン
- ルームから抜けるボタン
- ルーム解散ボタン

### 右側
参加プレイヤー欄とチャット欄は**別のボックスとして分離**して表示する。
- 参加プレイヤーボックス:実際にルームへ参加している人だけを表示する(未参加の空き枠は表示しない)。ルーム作成直後はGM本人のみが表示された状態になる
- チャットボックス:独立した下部の枠。宛先選択・入力欄に加えて**送信ボタン**を設置する

### 右上
- 設定(歯車)アイコン ※ルール項目は含めない

## 権限
ゲームマスター(ルーム作成者)にのみ以下を表示。参加者には**完全に非表示**(グレーアウトではなく要素自体を表示しない)。
- ゲーム開始ボタン
- ルーム解散ボタン
- モード選択などの各種設定項目(ゲーム設定モーダル内)
- ゲーム設定ボタン

ロール判定は、タイトル画面での遷移経路(「AI戦」「ルーム作成」→GM / 「ルーム参加」→参加者)で決まる。

## ゲーム開始の条件
- 参加プレイヤーが**2人以上**いない場合、「ゲーム開始」ボタンは押せない(非活性表示)。1人(GMのみ)の状態では開始不可

## ゲーム設定ボタンの項目
タップするとモーダルが開き、以下の項目を設定できる(**モード選択が一番上**)。
- **モード選択**(ノーマル/ロストフル。デフォルトは**ロストフル**)
- **初期チップ**(デフォルト1000を想定)
- **ラウンド数**
- **ビッグブラインドの金額**(デフォルト40。スモールブラインドは自動的にこの半分の金額になる)
- **ジョーカーの有無**(チェックボックス)
- **ジョーカーの枚数**(「ジョーカーの有無」がオンの時のみ設定可能。デフォルト2枚、山札は52+ジョーカー枚数になる)
- 他プレイヤーの**赤札推定額(ロストイン用)表示**のオン/オフ
- 他プレイヤーの**チップ額表示**のオン/オフ
- 他プレイヤーの**BET額表示**のオン/オフ
(表示トグルは混沌の「敵ライフ/マナ表示オン/オフ」と同じ方針。オフの項目は代替表示なしで完全非表示)

## チャット機能
混沌と同様の仕様。
- 宛先選択(「全体」または個別プレイヤー指定)
- 全体チャット/個別チャットの色分け表示(混沌ではゲーム画面で白文字/青文字)
- 送信ボタン
