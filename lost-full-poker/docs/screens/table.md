# 対戦卓画面 仕様

手書きラフを基に作成。

## レイアウト
### 上部
- 他プレイヤー(プレイヤー2、プレイヤー3…人数分)のエリアを横に並べて表示
- 各プレイヤーのエリアにも、自分のステータスエリアと同様に上から以下の順で表示:
  1. 推定換金金額(赤札・ロストイン用)
  2. チップ額表示
  3. 現在のBET額表示
- これら3項目(赤札推定額・チップ額・BET額)は、それぞれ個別にルームのゲーム設定から表示オン/オフを切り替えられる(混沌の「敵ライフ/マナ表示オン/オフ」と同様の方針)。オフの場合は該当項目を完全に非表示にする(代替表示はしない)
- 各プレイヤーのエリアに**ポジションバッジ**(BTN・SB・BB・UTG・HJ・CO)を表示し、一目で誰がどのポジションか分かるようにする(自分がそのポジションの場合は自分のステータスエリアにも同様に表示)。人数に応じたポジション名の割り当てはルール仕様書の「ポジション名」を参照。2人対戦時はBTNとSBを兼任するため「BTN/SB」の1つのバッジにまとめる

### 右上
- 「**降参**」「**退室**」ボタンを設置(混沌と同様の配置方針)。押すとそれぞれ「本当に〇〇しますか?」の再確認モーダルが表示される。降参は観戦モードへの移行(このゲームからの脱落)、退室はタイトル画面へ戻る操作

### 左下(自分のステータスエリアの上)
- 「**ゲームログ**」ボックスを設置。直近のアクション(ブラインド支払い、ベット、フォールドなど)を時系列で表示する

### 左上
- 「残りラウンド(ゲーム数)」表示ボックス(例:残りラウンド 3)

### 中央
- コミュニティカードの**左側**に「使用済みカード置き場」を配置(フォールドされたカードや不要になった山札の一部など、ゲームで使用済みのカードをまとめる場所)
- **コミュニティカード5枚**を横並びで配置。フロップ・ターン・リバーの進行に応じて、だんだんと1枚ずつ公開されていく
- コミュニティカードの右側に「**山札**」(残り枚数表示)のボックスを配置

### 中央〜下寄り
- 自分のホールカード(2枚)を**表向き**で表示する(数字・マークが見える状態。他プレイヤーのホールカードは裏向きで見えない)。「ホールカード」ラベル付きの矢印で該当エリアを示す

### 左下:自分(プレイヤー1)のステータスエリア
上から以下の順で縦に並べる:
1. 身体状態アイコン(タップで換金パネルを開く) + **推定換金金額(赤札・ロストイン用)**
2. チップ額表示(所持チップ)
3. 現在のBET額表示

### 右端
- 画面端からタブ状に飛び出た「換金へ」ボタン。タップすると**画面遷移せず**、対戦卓画面の上に換金パネルが右からスライドインする形で表示される(オーバーレイ)。パネル内の「戻る」または背景タップで閉じ、対戦卓に戻る(卓の状態は保持されたまま)

### 右下:アクションボタン
チェック・レイズ・コール・オールイン・ロストイン・フォールドの6つを配置。
- **チェック**:自分より前に誰もベット/レイズしていない場合のみ押せる(レイズが来ている場合は非活性)
- **コール**:自分より前に誰かがベット/レイズしている場合のみ押せる(誰もレイズしていない場合は非活性)
- **レイズ**:押すと対戦卓画面の上にレイズパネルがオーバーレイ表示される。レイズ量を数値で入力(最大値はその時点のBETの2倍まで)。「キャンセル」「確定」ボタンで操作
- **フォールド・オールイン・ロストイン**:押すと「本当に〇〇しますか?」の再確認モーダルが表示され、確定操作をしないと実行されない(誤操作防止)

### アクション順
BTNから時計回りの順に各プレイヤーがアクションする。

## 備考
- 赤札(推定換金金額)は残存部位のチップ換算額の合計値をリアルタイムに計算して表示する
- 换金への導線は「プレイヤー1エリアの身体アイコン」と「右端の換金タブ」の2箇所(どちらも同じスライドパネルを開く)
- 換金パネルの中身(人型の全体図・パーツ選択・換金ボタン)は[[exchange]]画面と同一内容。ただし独立した画面としてではなく、対戦卓画面上のオーバーレイとして実装する
- 換金を実行すると、自分のステータスエリアの「赤札(推定)」がその場で再計算され、実際に失った部位の合計額と一致する(心臓は合算対象外)。腕を失った際に連鎖喪失する指は合算されない
- 対戦卓に表示する他プレイヤーは、ルーム作成画面で実際に参加していたメンバーをそのまま引き継ぐ(固定の仮名は使わない)。BTNは自分から時計回りにSB→BB→…の順で役割を割り振る
