# タイトル画面 仕様

『混沌』のタイトル画面構成を踏襲。

## レイアウト
- 左上:ゲーム名「ロストフルホールデム」
- 右上:設定アイコン(歯車)※ルール項目は含めない。設定内容は今後実装
- ゲーム名下:プレイヤー名入力欄(プレースホルダー「プレイヤー1」、1〜10文字で名前を決定)
- 中央左寄り:メニューボックスを縦に並べる
  - AI戦
  - ルーム作成
  - ルーム参加
- 右下寄り:クレジットボタン

## 備考
- モード選択(ノーマル/ロストフル)はタイトル画面には置かず、ルーム作成時に選択する
- AI戦選択時、AIの難易度を1〜10で設定できる(混沌の仕様を踏襲)
