# ルーム参加画面 仕様

『混沌』のルーム参加画面構成をそのまま踏襲。

## ルームコードについて
ルームコードは**4桁の数字**。Colyseusが自動発行する内部roomIdとは別に、サーバー(`PokerRoom.onCreate`)が
ルーム作成のたびに重複しないよう4桁のコードを発行し、ルームのmetadataとして公開している。
クライアントは入力されたコードから`client.getAvailableRooms("poker")`で該当ルームを検索し、
実際のroomIdでjoinする(詳細は`server/CLIENT_PROTOCOL.md`参照)。

## レイアウト
- ルームコード入力欄(4桁数字)
- 1〜9・0のテンキー
- 入力クリア用ボタン
- 決定ボタン
- 閉じる用の「戻る」ボタン
