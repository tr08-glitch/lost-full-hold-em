# ロストフルホールデム ルール仕様書

## 概要
テキサスホールデムをベースにした、ホラー×ベット要素のオリジナルカードゲーム。
参加人数:2〜6人

## モード
| モード | 内容 |
|---|---|
| ノーマルモード | 通常のテキサスホールデム(身体換金要素なし) |
| ロストフルモード | 身体パーツ換金・ストレス値・ロストインを含む本作独自ルール |

モードはルーム作成時に選択する。

## 勝利条件
設定したラウンド数が終了した時点で、**所持チップが最大のプレイヤーが勝利**。
心臓・肺・ロストインなどで死亡したプレイヤー、廃人になったプレイヤーの順位は「死亡・廃人と順位」(ロストフル節)に従う(ラウンド切れ終了ならスコア×0.7で勝者になり得る。それ以外の終了では全員敗北)。

## 基本ルール(ノーマルモード)
標準的なテキサスホールデムのルールに準拠。
- コミュニティカード5枚 + 各プレイヤーホールカード2枚
- ベッティングラウンド:プリフロップ→フロップ→ターン→リバー
- 役の強さで勝敗を決定

### 役の一覧(強い順)
| 順位 | 役 | 説明 |
|---|---|---|
| 1 | ロイヤルフラッシュ | 同スートA-K-Q-J-10 |
| 2 | ストレートフラッシュ | 同スートの連番5枚 |
| 3 | フォーカード | 同ランク4枚 |
| 4 | フルハウス | スリーカード+ワンペア |
| 5 | フラッシュ | 同スート5枚(連番でなくてよい) |
| 6 | ストレート | 連番5枚(スート不問。A-2-3-4-5も成立し、この場合Aは1として扱う) |
| 7 | スリーカード | 同ランク3枚 |
| 8 | ツーペア | ペア2組 |
| 9 | ワンペア | 同ランク2枚 |
| 10 | ハイカード | 上記いずれも成立しない場合、最も高いカードで比較 |

同役の場合はキッカー(残りの手札)の高さで比較する。それでも同じ場合は引き分け(ポットを山分け)。

### ベットの単位・上限
- 既にベットが入っている状態への**レイズ**に上限は設けない(最小は現在のBET額+SB、最大は自分のチップ残高まで)
- 最小ベット単位はSB額刻みを推奨
- **オープニングベット**(そのベッティングラウンドでまだ誰もベットしていない状態、現在のBET額が0の場面での最初のベット。フロップ以降で発生しうる)には上限を設けない。最小はSB額、最大は自分のチップ残高まで(=事実上のオールインと同額まで)ベット可能

### 通常時(ロストイン以外)のオールイン・サイドポット
- チップが足りずオールインした場合、その額を上限にメインポットが成立し、残りのプレイヤー間でサイドポットが別途形成される(ロストインのサイドポット処理と同じ考え方)
- オールインしたプレイヤーはそれ以上ベットできないが、ショーダウンには参加できる

### 基本操作フロー
- 全員が同額を出す/降りるまで、そのベッティングラウンドは終わらない
- フォールドせずに残っているのが1人になった時点で、ショーダウンなしでそのプレイヤーの勝利(即ポット獲得)
- **ヘッズアップ(2人対戦)時の特例**:BTNがSBを兼ねる(BTN=SB、もう1人がBB)
- **ショーダウンの順番**:最後にベット/レイズしたプレイヤーから先に公開。誰もベットしていなければBTNから時計回りに公開

## ゲーム進行

### 試合の流れ(全体像)
1. ルーム作成:GMがモード・初期チップ・ラウンド数・BB額・ジョーカー設定などを決めてルーム作成
2. 参加者がルームコードで参加(2〜6人)
3. GMが「ゲーム開始」を押すと試合開始(以降、新規参加は締め切り)。最初のBTNをランダムに決定
4. 各ラウンド:BTN確定 → ホールカード配布 → SB/BB徴収 → プリフロップ → フロップ → ターン → リバー → ショーダウン(または途中全員フォールドで即決着)→ ポット分配 → 次ラウンドへ(BTNが時計回りに1つ移動)
5. 設定ラウンド数が終了したら試合終了。**その時点でのチップ最大のプレイヤーが優勝**

### チップが0になったプレイヤー(バスト)の扱い
ノーマルモードには生存/死亡の概念が無く、勝敗はラウンド数終了時のチップ量だけで決まる仕様のため、チップ0になっても即座にゲームオーバーにはならない。
- バストしたプレイヤーは、ロストフルモードの廃人・死亡と同様に**以降のラウンドの進行から除外**される(観戦扱い)
- チップ0のままゲーム終了を迎えるので、その時点のチップ量(0)で最終順位が決まる(優勝はできない)

### 通信切断中のプレイヤーの自動フォールド
自分の手番が回ってきてから**30秒間操作がない場合、自動的にフォールド**する(通信切断中に限らず、単純に操作しなかった場合も同様)。

### 最初のBTN(ディーラーボタン)決定
ゲーム開始時、**ランダムに**最初のBTNを決定する。

### ラウンド開始時の配札
ラウンド開始時、各プレイヤーに**ホールカード**(手札のこと。本仕様書では以降「ホールカード」と表記する)を**2枚**配る。

### BTNの移動
ラウンドが変わるごとに、BTNは**時計回りに1人分ずつ移動**する。

### アクション順
各ベッティングラウンドでのアクションは、**BTNから時計回り**の順に行う。

### ポジション名・座席順
各プレイヤーの卓上での立ち位置(ポジション)には名称を付け、対戦卓画面でバッジとして表示する。
標準的な6-maxの呼称(UTG→HJ→CO→BTN→SB→BB)をベースに、人数が少ない場合はUTG側(BTNから最も遠い位置)から順に間引く。

以下は**座席順(BTNから時計回りに並んだ物理的な席順、バッジ表示・BTN移動の基準)**:

| 人数 | 座席順(BTNの次から時計回り) |
|---|---|
| 2人 | BTN/SB → BB |
| 3人 | BTN → SB → BB |
| 4人 | BTN → SB → BB → UTG |
| 5人 | BTN → SB → BB → UTG → CO |
| 6人 | BTN → SB → BB → UTG → HJ → CO |

- 2人時はBTNとSBを兼任するため、バッジは「BTN/SB」の1つにまとめて表示する
- ポジションはラウンドごとにBTNの移動に連動して再計算される

### プリフロップのアクション順
座席順とは別に、**プリフロップの行動順(誰から発言するか)**は以下の通り(BBが必ず最後):

| 人数 | プリフロップの行動順 |
|---|---|
| 2人 | BTN/SB → BB |
| 3人 | BTN → SB → BB |
| 4人 | UTG → BTN → SB → BB |
| 5人 | UTG → CO → BTN → SB → BB |
| 6人 | UTG → HJ → CO → BTN → SB → BB |

- 4人以上はUTG(BBの次の座席)から開始。2〜3人はUTGが存在しないためBTNから開始(2人はBTN/SBから)
- フロップ以降(ポストフロップ)は座席順どおり、BTNの次(=SB側)から時計回りに開始する。この違いはプリフロップのみの特例

### プリフロップのBBオプション
全員がコールしてBBまで回ってきた場合、BBは追加でレイズする権利を持つ(チェックで終わることも可能)。

### 最小レイズに満たないオールイン(ショートオールイン)の扱い
チップ不足で最小レイズ額に満たない額のオールインをした場合、それは「正規のレイズ」として扱わない。
- 現在のBET額(コールに必要な額)はそのオールイン額まで更新される
- ただし、それ以前に**既に行動済みかどうかに関わらず**、他のプレイヤーは「コール」または「フォールド」のみ選択可能で、レイズを打ち返すことはできない
- 誰か(そのオールインより後に行動する別のプレイヤー)が正規サイズのレイズを行った時点で、以降は通常どおり全員がレイズ可能になる(標準的なノーリミットホールデムのルールに準拠)

### ブラインド
- **ビッグブラインド(BB)**:ゲーム設定で金額を指定できる(デフォルト40)
- **スモールブラインド(SB)**:BBの半額。自動的に決まる(デフォルト20)
(通常の目安であるSB5/BB10の4倍を初期値とした。ロストフルモードでの身体パーツ換金を絡めた駆け引きが早めに発生するよう、やや厚めに設定)

## 山札の管理
- 山札はトランプ1組(**52枚**)。ゲーム設定で**ジョーカーの有無**をチェックボックスで選択でき、オンの場合のみ「ジョーカーの枚数」(デフォルト2枚)を設定できる。山札は52枚+ジョーカー枚数になる

### ジョーカーの役判定上の扱い
- **完全ワイルドカード**:手札・コミュニティカードにジョーカーが含まれる場合、任意のカードとして扱い、そのプレイヤーにとって最も強い役を作れる(2枚とも引いた場合は2枚とも独立にワイルドとして扱う)
- **ロストフルモード限定の効果**:ジョーカーを手札(ホールカード)として配られたプレイヤーは、配られた時点でストレス値が**1枚につき5**上昇する(2枚ともジョーカーなら合計10)。ノーマルモードではこの効果はない
- 1ラウンドで消費する枚数は「プレイヤー人数×2枚(各プレイヤーのホールカード) + 5枚(コミュニティカード)」。**バーンカードは導入しない**(シンプルさ優先の判断)
- ラウンド終了時、使用したカードは全て「使用済みカード置き場」に移動する
- 次のラウンドは残りの山札から続けて配る
- 次ラウンド開始前に**残り山札の枚数が必要枚数に満たない場合**、使用済みカード置き場の全カードを回収し、新しい山札としてシャッフルし直してから配り始める

## ロストフルモード:身体パーツ換金システム

チップの有無に関わらず、**任意のタイミングで身体パーツをベットに変換できる**(不可逆)。
変換時には専用の演出(グロ描写)が入る。右上の「ステータス」パネルで、状態・ストレス・デバフを確認できる。

### 部位一覧(最新)

| 部位 | 換金回数 | チップ | ストレス | 効果 |
|---|---|---|---|---|
| 指 | 1本ずつ(左5本・右5本) | 20 | 3 | カードを落としやすくなる(下記「指とカードの落下」)。4本以上で常時公開。左手=左の手札、右手=右の手札 |
| 歯 | 1回のみ | 200 | 10 | 以降のストレス上昇が**2倍**(歯を換金した回自体は等倍) |
| 耳 | **左右同時に1回のみ** | 140(70×2) | 20(10×2) | 音が聞こえなくなる(音声は未実装) |
| 肺(片方) | 左右各1回 | 150 | 25 | 片肺:視界に赤いもや。**両肺で死亡** |
| 目(片方) | 左右各1回 | 250 | 15 | 片目:カードの数字が見えない(マークのみ)。両目:数字もマークも見えない(自分の画面のみ) |
| 腕(片方) | 左右各1回 | 150 | 20 | チェック/コールのみ。同じ側の指5本も同時に喪失(連鎖分のチップ・ストレスは加算なし) |
| 心臓 | 1回のみ | 400 | なし | **即死** |

※耳の換金額・ストレスは、片耳ずつだった頃の合計(70×2、10×2)を引き継いでいる。

### 指とカードの落下(指の確率カーブ)

指を失った側の手(左手=左の手札、右手=右の手札)は、行動のたびに確率でカードを落とす。

| 喪失本数 | カードを落とす確率(行動のたび) |
|---|---|
| 1本 | 5% |
| 2本 | 15% |
| 3本 | 30% |
| 4〜5本(腕を失った側を含む) | 確率判定なし。指が2本以下ではカードを持てないため、その側のカードは**卓の上に表向きに置いてプレイ**する(常時公開)。画面では、本人のカードは手元から卓へ、相手のカードは座席の下の卓上に置かれる |

- 判定タイミングは「アクションを選択する瞬間」。
- 落とすと、そのカードが卓にこぼれ落ち、**約3.5秒間だけ全員に見える**。その後、手が伸びてカードを拾い直し、非公開に戻る(演出:落下→手が拾う→手元へ戻る)。
- 落ちている間は、同じ手では再判定しない。拾い直した後の次の行動で、また判定される。
- ラウンドが変わると、落ちている状態はリセットされる。

### 腕のルール
腕を片方でも失うと、自分のターンは**チェックまたはコール**しか選べない(レイズ・フォールド不可)。
- **コール扱いのオールイン**は可能(手持ち全額でも現在のベット額に届かない場合など)。
- **ロストインの宣言・対抗ロストイン**は、腕を失っていても可能。ロストインへの応答では、手持ちが赤札額以下の場合のオールインも可能。

### ストレスと廃人
- 換金するたびに部位ごとのストレスが加算される。**100に到達すると廃人**(ゲームに参加できなくなる)。
- ジョーカーが手札に配られるたび、ストレス+5(ロストフルモードのみ)。
- 死亡・廃人になる換金は、実行前に確認が出る。

### 死亡・廃人と順位
- **ラウンド切れで終了**:死亡・廃人のスコアは「チップ×0.7」。そのスコアで順位を決める(死んでも勝者になれる)。
- **それ以外で終了**(生存者が1人以下など):死亡・廃人は**全員敗北**(生存扱いの人より下)。
- 降参者は常に最下位(先に降参した人ほど下)。

### 心臓・肺(死亡時)
心臓、または両肺を失った時点で死亡。血の椅子が卓に残る。

## 特殊技「ロストイン」

残っている身体の部位を**すべて(心臓も含む)**一括でベットに変換し、そのままオールインする捨て身の特攻技。

### 発動フロー
1. 宣言時、残存全部位の換算チップ合計(心臓400を含む)を**赤札**として提示(この時点では身体は失わない)。
2. 他プレイヤーは宣言者の次から順番に、以下から選ぶ:
   - **コール**:赤札と同額を通常チップで支払う(足りなければ手持ち全額)
   - **オールイン**:手持ちを全て賭けて応じる
   - **対抗ロストイン**:自分もロストインする
   - **フォールド**
3. **全員フォールド**:不発。身体は失わず、宣言者が通常ポットを回収。
4. **コール/オールイン/対抗ロストインが出た時点で実行確定**:宣言者(と対抗者)が全部位を失う。応答済みでない他のプレイヤーは自動フォールドになり、コール/オールインした人は勝負に残る。場が全て開いてジャッジへ進む。
5. **ロストインを実行したプレイヤーは、勝敗に関わらず死亡**。
6. 応答待ちで時間切れになった人は、フォールドとして扱う。

## 実装状況
身体パーツ換金(指・歯・耳・肺・目・腕・心臓)とロストインは、いずれも`server/CLIENT_PROTOCOL.md`に記載の
メッセージ(`exchangeBodyPart` / `action:{type:"lostin"}`)としてサーバーに実装済み。対戦卓画面(table.html)の
換金ドロワー・ロストインボタンも実サーバー連携済み。

## 未確定・今後詰める項目
- 各部位のチップ額・ストレス値の最終バランス確認(全喪失時にストレス100を超えるため、ロストイン成立時の扱いに注意)
- 廃人・死亡時の卓上演出の細部(血痕の蓄積表現など)。現状はログ表示のみ
- ロストフルモードの設定項目の詳細(ルーム設定画面で今後実装)
- 耳(無音)の演出は音声自体が未実装。目(数字/マークが見えない)・肺(赤いもや)の視覚演出はクライアントに実装済み

## 切断時の扱い
- 切断したプレイヤーには30秒の復帰猶予があり、他プレイヤーの画面にその残り秒数が赤字で表示される。
- 30秒以内に復帰しなかった場合は強制敗北(降参と同じ扱いで最下位グループ)となり、ルームから退出させられる(クライアントはタイトルへ戻る)。
- 復帰できればそのままゲームを続行できる。
