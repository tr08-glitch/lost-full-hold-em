# 身体パーツ換金画面 仕様

手書きラフを基に作成。

## レイアウト
### 中央
- 人型の全体図イラスト(換金するパーツを視覚的に選ぶための参照図)
- **換金済みの部位は黒く表示**し、どのパーツを既に失っているか一目で分かるようにする

### 左端
- 画面端からタブ状に飛び出た「戻る」ボタン(タップで対戦卓画面にスライド遷移)

### 下部
- 「換金するパーツ」選択ドロップダウン(例:指、歯、耳(左/右)、肺(左/右)、目(左/右)、腕(左/右)、心臓)
- 「換金」ボタン(選択したパーツを実際に換金する。確認ダイアログ→グロ演出→ストレス値・チップ反映という流れを想定)

## 備考
- 全体図は「パーツの残りを確認」できることが目的。換金済みの部位を黒くすることで、現在の身体状態が視覚的に一目で把握できる
- ドロップダウンには、既に換金済みで選択できないパーツ(例:既に失った指)は表示しない、またはグレーアウトする想定
